## <a name="overview"></a>Overview
<p align="justify"> The CSHB code is a Fortran implementation of equations of state for pure fluids and multicomponent mixtures represented by cylindrically symmetric hard bodies. The supported convex molecular geometries include ellipsoids of revolution (EOR), spherocylinders (SPC), and cylinders (CYL), whose components may differ in size, aspect ratio, and geometry. The repulsive reference contribution is described from the geometrical properties and second virial coefficients of the convex bodies, using the Parsons–Lee decoupling approximation or the scaled-particle-theory formulation. Cross interactions in mixtures are determined through geometrical combining rules based on the Isihara–Hadwiger theorem. Attractive interactions can be represented by either a spherical square-well field in the CSHB–SSW equation of state or a convex square-well field in the CSHB–CSW equation of state. Both formulations employ the Barker–Henderson perturbation theory up to second order, including optional corrections for the second-order perturbation contribution. The code evaluates thermodynamic properties such as the residual Helmholtz free energy, pressure, compressibility factor, chemical potential, fugacity coefficient, and phase densities. It also includes calculation routes for pure-component critical properties, vapor-pressure and coexistence curves, parameter estimation, and liquid–vapor equilibrium of binary and multicomponent mixtures. Density roots are identified and classified using the Topliss procedure and solved numerically with Brent’s method. Multicomponent flash calculations employ Wilson estimates for the initial equilibrium factors, phase-state tests, the Rachford–Rice equation for the vapor fraction, and successive substitution of the fugacity-based equilibrium factors. Pure-component parameters and binary interaction parameters can be optimized using the Nelder–Mead simplex method against experimental vapor-pressure, saturated-liquid-density, and phase-equilibrium data. </p>

## <a name="features"></a>Features
<p align="justify">
The following features are supported in the current version:
</p>

1. Systems
    - Pure components
    - Multicomponent mixtures

2. Molecular Geometries
    - Ellipsoids of Revolution (EOR)
    - Spherocylinders (SPC)
    - Cylinders (CYL)
    - Mixtures containing different molecular geometries when non-spherical mixing rules are selected

3. Interaction Potentials
    - Spherical Square-Well (SSW)
    - Sutherland
    - Yukawa
    - Convex Square-Well (CSW)

4. Reference and Perturbation Systems
    - Parsons-Lee reference term
    - Boublik reference term
    - Barker-Henderson thermodynamic perturbation theory
    - Zhang correction for the second-order perturbation contribution
    - Optional higher-order perturbation contributions
    - Percus-Yevick correction to the HCB isothermal compressibility

5. Thermodynamic Property Routes
    - Isothermal calculations
    - Isobaric calculations
    - Isochoric calculations
    - Molar and mass densities
    - Molar volume
    - Isothermal compressibility
    - Thermal expansion coefficient
    - Compressibility factor
    - Entropy
    - Specific heats at constant volume and constant pressure
    - Speed of sound
    - Joule-Thomson coefficient
    - Total and residual chemical potentials

6. Phase-Equilibrium Calculations
    - Pure-component critical properties and vapor-liquid coexistence curves
    - Binary vapor-liquid equilibrium (VLE) at fixed temperature
    - Topliss procedure for bracketing density roots
    - Brent's method for numerical root finding
    - Wilson correlation for initial equilibrium factor estimates in binary VLE calculations
    - Rachford-Rice equation and successive substitution for binary flash calculations

7. Parameter Optimization
    - Nelder-Mead simplex optimization
    - Pure-component optimization of well depth, potential range, molecular diameter, and aspect ratio against vapor pressure and saturated liquid density data
    - Binary optimization of the unlike well depth correction factor and, optionally, the unlike potential range correction factor against VLE data

## <a name="installation"></a>Building and Compiling
<p align="justify">
  Firstly, you must clone this GitHub repository using the command below:
</p>

```
git clone https://github.com/LESC-Unicamp/Supplementary-materials/
```

<p align="justify">
  After that, change to the repository directory on your device and open the <code>/src/</code> folder:
</p>

```
cd Supplementary-materials/A-new-molecular-based-equation-of-state-for-mixtures-of-cylindrically-symmetric-hard-bodies/Equation-of-state/src/
```

<p align="justify">
  The <code>/src/</code> folder contains one 'Makefile' file that you can use to compile the code.
</p>

<p align="justify">
  To compile it, first remove any object and module files using the <i>clean</i> command:
</p>
  
```
make clean
```

<p align="justify">
  Then, to compile the source code, run the command below:
</p>

```
make -f makefile
```

<p align="justify">
  This command will produce an executable file that can be found in the folder <code>/bin/</code> in the repository directory. Before running the program, there are a few initialization variables and options you need to set up.
</p>
