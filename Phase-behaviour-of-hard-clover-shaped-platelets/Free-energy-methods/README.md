## <a name="overview"></a>Overview
<p align="justify">
  This code implements free-energy methods for systems of nonconvex clover-shaped hard particles formed by the union of four identical cylinders. The program provides the thermodynamic-integration contributions required to determine the Helmholtz free energy of crystalline solids and liquid-crystalline phases. Solid free energies are evaluated using the <a href="https://doi.org/10.1063/1.448024"><b>Frenkel–Ladd method</b></a>, in which the solid is connected to an Einstein-crystal reference state. Liquid-crystal free-energy calculations employ the <a href="https://doi.org/10.1080/00268978500101971"><b>Frenkel–Mulder method</b></a>, in which the phase of interest is connected to an externally oriented fluid through an orientational field.
</p>

<p align="justify">
  The Frenkel–Ladd route is divided into three calculations. <code>A0</code> evaluates the translational and orientational ideal contributions associated with the Einstein-crystal reference, including the centre-of-mass constraint used by the method. <code>ΔA1</code> evaluates the free-energy change between the interacting and non-interacting Einstein crystals from the fraction of sampled non-overlapping configurations. <code>ΔA2</code> evaluates the free-energy change between the solid and the interacting Einstein crystal by Hamiltonian thermodynamic integration using a 20-point Gauss–Legendre quadrature. The Frenkel–Mulder route evaluates <code>ΔAfield</code>, the free-energy change between the externally oriented fluid and the liquid-crystalline phase, also using a 20-point Gauss–Legendre quadrature over the orientational-field strength.
</p>

<p align="justify">
  The particles interact through a purely repulsive hard-core potential. Trial configurations are sampled in the canonical ensemble using translational and rotational Monte Carlo moves, with rotations represented by quaternion algebra. The initial solid configuration is generated by periodically replicating a unit cell read from <code>Floppy-box/fbox.dat</code>, whereas liquid-crystalline configurations are read directly from <code>Liquid-crystal/lc.dat</code>. Two cross-sectional arrangements of the four-cylinder clover geometry are supported, as illustrated below.
</p>

## <a name="features"></a>Features
<p align="justify">
The following features are supported in the current version:
</p>

1. Free-Energy Methods
    - Frenkel–Ladd method for crystalline solids
    - Frenkel–Mulder method for liquid crystals

2. Initial Configurations
    - Floppy-box unit-cell configuration (<code>FB</code>) for solids
    - Liquid-crystal configuration (<code>LC</code>) containing particle positions, orientations, and box dimensions

3. Particle Geometry
    - Nonconvex clover-shaped particles composed of four identical cylinders
    - Two cross-sectional arrangements with different degrees of concavity

4. Canonical Moves
    - Translation
    - Rotation (Quaternion Algebra)

5. Numerical Integration
    - Monte Carlo integration for the orientational contribution to <code>A0</code>
    - 20-point Gauss–Legendre quadrature for <code>ΔA2</code> and <code>ΔAfield</code>

6. Additional Features
    - OpenMP parallelization of overlap-detection routines

## <a name="language"></a>Language
<p align="justify">
  The main program, subroutines, and modules contain explanatory comments and are mainly written in Fortran 95. The source is compiled with GNU Fortran (<code>gfortran</code>) and uses the OpenMP API for parallel sections of the overlap-detection algorithm. The user can look for more information on the Fortran language <a href="https://docs.oracle.com/cd/E19957-01/806-3591/C_f95.html">here</a>.
</p>

<p align="justify">
  The code creates directories by executing shell commands through the intrinsic function <code>SYSTEM</code>. The current implementation is therefore intended for Linux operating systems and Linux subsystems.
</p>

## <a name="installation"></a>Building and Compiling
<p align="justify">
  Firstly, you must clone this GitHub repository using the command below:
</p>

```
> git clone https://github.com/LESC-Unicamp/Supplementary-materials/
```

<p align="justify">
  After that, change to the repository directory on your device and open the <code>/src/</code> folder:
</p>

```
cd Supplementary-materials/Phase-behaviour-of-hard-clover-shaped-platelets/Free-energy-methods/src/
```

<p align="justify">
  The <code>/src/</code> folder contains a <code>makefile</code> that compiles the code with GNU Fortran and OpenMP support.
</p>

<p align="justify">
  To compile it, first remove any object, module, and previously generated executable files using the <i>clean</i> command:
</p>
  
```
> make clean
```

<p align="justify">
  Then, compile the source code using the command below:
</p>

| **Compilation type** | **Command** |
|:---:|:---:|
| <a href="https://github.com/LESC-Unicamp/Supplementary-materials/blob/main/Phase-behaviour-of-hard-clover-shaped-platelets/Free-energy-methods/src/makefile">Standard (with OpenMP)</a> | ```make -f makefile``` |

<p align="justify">
  Please note that the compilation supports parallelization via OpenMP. In this case, it is recommended to set the number of threads using the following command:
</p>

```
> export OMP_NUM_THREADS=X
```

<p align="justify">
where <code>X</code> is the number of threads.
</p>

<p align="justify">
  This command will produce an executable named <code>free-energy-method.out</code>, which can be found in the folder <code>/bin/</code> in the repository directory. Before running the program, there are a few initialization variables and options you need to set up.
</p>
